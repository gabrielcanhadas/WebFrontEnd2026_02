O que é CSS

Quando iniciamos o processo de aprendizado no contexto de Programação Web Frontend, HTML é a primeira linguagem da qual temos contato, uma vez que é via HTML que inserimos o conteúdo e definimos a estrutura de uma página Web. O passo seguinte nesse processo de aprendizado é atuar com CSS, para que possamos encontrar meios para adicionar estilo à página Web desenvolvida.

Em CSS, para aplicar o estilo em uma página Web, o navegador é responsável por converter as regras CSS em um mapa de estilos CSS Object Model (CSSOM), ou Modelo de Objeto CSS, da mesma forma que em HTML existe o modelo DOM.

A partir desse mapa, ele passa por cada regra definida no CSS, criando uma árvore de nós, com base nos seletores CSS que foram especificados. Ou seja, ocorre um processo similar ao objeto DOM, para renderizar o conteúdo HTML. É a partir do CSSOM também que temos a possibilidade de manipular o CSS por meio do JavaScript, como veremos mais adiante na disciplina.
